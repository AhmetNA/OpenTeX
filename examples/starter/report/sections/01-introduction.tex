\section{Introduction}
This starter project demonstrates local LaTeX editing with Rapor. Select a source file on the left, edit it in the centre, and compile a PDF on the right.

\subsection{References}
The bibliography workspace displays references as readable records and edits their fields while preserving the underlying BibTeX. The LaTeX project provides documentation about document preparation \citep{latex}, and Tectonic supplies the local compilation engine \citep{tectonic}.

\subsection{Try It}
Change this paragraph, compile the report, and select a phrase in the PDF to reveal its source. Reverse navigation matches rendered text with source text; equations and generated page labels may not have an unambiguous destination.
